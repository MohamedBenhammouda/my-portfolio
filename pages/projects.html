Nov 2024 – Feb 2025 React · Node.js · Express.js · JSON File Database · REST API

The project involved building a responsive React frontend for content consumption and administration, backed by a robust Node.js and Express REST API utilizing a custom JSON file-based database for lightweight, file-system data persistence.

Backend Architecture & API Development

  • Express.js REST API: Designed and implemented a comprehensive RESTful API to handle all CRUD operations for website content, including pages, blog posts, team members, and services.
  • Custom JSON Database: Engineered a lightweight data persistence layer using structured JSON files. Implemented asynchronous file read/write operations with built-in data validation and file-locking mechanisms to prevent race conditions during concurrent updates.
  • Middleware & Security: Integrated Express middleware for CORS, JSON body parsing, request logging, and custom global error handling to ensure API reliability and secure data transmission.
  • MVC Structure: Structured the backend using the Model-View-Controller pattern to maintain a clean separation of concerns, resulting in highly maintainable and scalable server-side code.

Frontend & Admin Dashboard (React)

  • Dynamic Public Website: Built a fast, SEO-friendly public-facing website using React, fetching content dynamically from the backend API to render pages without hardcoding HTML.
  • Admin CMS Dashboard: Developed a secure, intuitive administrative panel allowing non-technical staff to create, edit, publish, and delete website content seamlessly.
  • State Management & Routing: Utilized React Router for seamless single-page application (SPA) navigation and React Context API for global state management, handling user sessions and UI themes.
  • Rich Text & Media Handling: Integrated a rich text editor for blog posts and implemented an image URL management system to handle visual assets and formatting dynamically.

Key Features & System Optimization

  • Real-Time Preview: Implemented a live-preview feature in the admin dashboard, allowing content creators to see exactly how changes would appear on the public site before finalizing publication.
  • Data Seeding & Migration: Created automated Node.js utility scripts to seed the JSON database with initial corporate data and handle schema migrations as project requirements evolved.
  • Performance Tuning: Optimized React component rendering using memoization and implemented API response caching on the frontend to minimize redundant network requests and improve load times.
  • End-to-End Testing: Conducted rigorous testing across both frontend and backend to ensure data integrity, proper error handling, and a bug-free user experience across all devices.
